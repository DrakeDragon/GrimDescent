# Grimm Descent — first art pass
Open index.html with the assets folder alongside it. Original download is untouched.

Included: generated eight-frame Huntsman sheet (4 columns, 2 rows: walk/attack), Hollow Woods painted backdrop, animated Canvas integration for hero knight, and forest/brass menu/button styling. Built-in image generation used. JavaScript syntax check and build passed; browser/mobile visual testing has not been completed. Sheet alignment and animation timing need visual QA before release.

This is an initial slice, not a completed graphical overhaul. Other heroes, enemies, bosses, pets and many UI icons retain original emoji. The Woods background currently covers campaign 0; remaining campaigns retain procedural backgrounds. Assets are external, so deploy the entire folder.

Art direction: painted dark fairytale, midnight teal, moss, aged brass, warm amber light; readable silhouettes at phone scale. Expand with individually approved hero sheets, enemy families, unique miniboss/boss sheets, ten campaign environments, then UI icon atlas. Keep character identities distinct rather than reusing the Huntsman across the roster.

Generation prompts:
Huntsman: transparent 4-column, 2-row sheet; same right-facing olive hood/leather cloak Huntsman with crossbow; four walk frames followed by four attack frames; consistent scale and baseline, generous cell padding, painted fantasy style, no text.
Hollow Woods: wide painted twisted forest, distant witch cottage with amber windows, midnight teal/moss palette, mist and moonlight; uncluttered earth path in lower 45 percent; no characters, text or interface.
